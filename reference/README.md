# reference/

Styling and content sources. Not deployed: `build.mjs` only copies `site/`.

The repo is public, so anything committed here is public too. Source documents (`*.docx`, `*.pdf`) are git-ignored.

- `screens/`: full-page screenshots of the live site (`<page>-<width>.png`)
- `css/`: the site's downloaded stylesheets
- `computed.json`: computed styles + bounding boxes
- `dom-*.txt`: markup outlines used to pick selectors
- `notes.md`: responsive behaviour of the projects table, breakpoints
- `live/`: sign-off screenshots from `check-embed.mjs`
